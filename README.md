# Invoice-generator
A simple invoice generator for small businesses in Kenya.

# Features
- Add your business name and client details
- Add or remove items
- Auto calculates subtotal, VAT(16%) and total
- Print or even save as pdf

  # How to use
  1. Open 'index.html'
  2. Fill in the business and client details
  3. Add items
  4. Click print or save as PDF
 
  # Tech Used
  - HTML
  - CSS
  - JavaScript
